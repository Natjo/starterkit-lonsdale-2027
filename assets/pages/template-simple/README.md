# Simple

Page courte composée d’un hero et d’une seule strate de texte.

À utiliser lorsqu’une page n’a pas besoin du constructeur de strates flexible.

Le champ WYSIWYG `text` propose un contenu Lorem ipsum par défaut dans son JSON
ACF. Forge reprend cette valeur pour une nouvelle contribution ; un texte déjà
saisi ou volontairement vidé est conservé.
