# Flexible sidebar

Page éditoriale composée librement avec des strates ACF et une colonne
latérale réservée au contenu propre au projet.

Le template fournit uniquement le layout. La zone `.main-sidebar` est vide
dans le starter afin que le site puisse y intégrer ses composants sans imposer
une navigation ou un contenu particulier. Les strates sont rendues dans
`.main-content`. Les deux colonnes sont regroupées dans `.main-layout`.

Le hero utilisé est `page`. Le CSS du template est compilé en `once` et
injecté inline lors du rendu de `template-flexible-sidebar.php`.
