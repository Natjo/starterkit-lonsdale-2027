# Contact

Page de contact avec un formulaire prêt à l’emploi.

À utiliser pour permettre aux visiteurs d’envoyer un message. Le formulaire peut fonctionner en AJAX et affiche directement les messages de succès ou d’erreur.

Le template affiche le hero `page`, déclaré dans son manifeste afin que Forge
l’ajoute automatiquement aux pages utilisant le modèle Contact.
