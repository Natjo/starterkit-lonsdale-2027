# Flexible nav anchor

Page éditoriale composée librement avec des strates ACF et une navigation
horizontale vers les sections de la page.

Les liens sont générés automatiquement depuis l’option `name` de chaque
strate. Une strate sans nom reste affichée dans la page, mais n’est pas ajoutée
à la navigation.

À utiliser pour une page longue dont les principales sections doivent rester
directement accessibles par des ancres.
