# Hub filters

Page générique de Content Type avec recherche, filtres de taxonomies, tri et
pagination.

Le Content Type est choisi dans Forge puis stocké dans la méta WordPress
`hub_post_type`. Les taxonomies publiques associées à ce type alimentent
automatiquement la colonne latérale.

La recherche, les filtres, le tri et la pagination utilisent AJAX lorsque
JavaScript est disponible. Les formulaires GET restent fonctionnels sans
JavaScript.
