Strate text-image

Affiche un bloc éditorial composé d’un titre, d’un texte riche et d’une image. À partir du breakpoint md, le contenu et le média occupent chacun une moitié du rail ctr.

Lire d’abord le README général des strates.

Appel

Depuis le flexible content ACF, le dispatcher appelle automatiquement :

strate('text-image', $strate);

Appel direct :

strate('text-image', [
    'title' => 'Titre de la section',
    'text' => '<p>Contenu éditorial.</p>',
    'image' => 123,
    'reverse' => true,
    'center' => true,
]);

Le nom du layout ACF est text-image. Le préfixe strate- appartient uniquement au dossier et au fichier PHP.

Le titre et le texte de démonstration viennent des default_value ACF. Le placeholder dédié mesure 1460 × 973 px, soit deux fois la largeur du format WordPress 730_auto. Il est déclaré dans le manifeste : Forge l’importe dans la médiathèque et remplace sa référence par l’identifiant propre au site créé.

Mise en page

Avant le breakpoint md, le texte et l’image sont empilés.

À partir du breakpoint md, ils occupent chacun une moitié du rail ctr :

  • reverse inverse leur position ;
  • center les centre verticalement.
