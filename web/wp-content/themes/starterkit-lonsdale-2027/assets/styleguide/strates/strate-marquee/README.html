Strate marquee

Affiche un défilement continu de cards ou d’images. Le starter utilise par défaut le mode images avec trois visuels de démonstration.

Lire d’abord le README général des strates et le README du composant marquee.

Appel

Cards :

strate('marquee', [
    'title' => 'À découvrir',
    'content_type' => 'cards',
    'post_type' => 'news',
    'items' => [123, 456],
]);

Images :

strate('marquee', [
    'content_type' => 'images',
    'images' => [
        ['image' => 123],
        ['image' => 456],
    ],
]);

Le mode HTML utilisé par le styleguide reste disponible lors d’un appel PHP :

strate('marquee', [
    'content_type' => 'html',
    'items' => ['<strong>Design</strong>', '<span>Digital</span>'],
]);

ACF propose automatiquement les CPT enregistrés qui possèdent une card de même nom. Dans le starter, le choix par défaut est news.

Les posts sélectionnés sont préchargés en lots avant leur validation par CPT. Les images sont ensuite préchargées par le composant marquee. Ce comportement s'applique à toutes les pages, archives et templates utilisant la strate.

Images

La taille WordPress est définie au début du template :

$image_size = 'full';

Les images utilisent picture avec fit => 'cover'. Le starter leur applique un ratio 3 / 2 et une largeur maximale de 48rem. Les trois placeholders de 960 × 640 px sont déclarés dans le manifeste puis importés par Forge. Ils sont partagés avec Columns Content afin d’éviter les doublons dans la médiathèque.

Hydratation

La strate possède le cycle de vie JavaScript. Elle force hydrate => false sur le composant et délègue pause, resume et destroy à son contrôleur.
