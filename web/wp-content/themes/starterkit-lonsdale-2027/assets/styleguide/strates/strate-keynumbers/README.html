Strate keynumbers

Affiche une introduction facultative suivie d’une liste de chiffres clés. Chaque item est rendu par card-keynumber.

Lire d’abord le README général des strates et le README de la card.

Appel
strate('keynumbers', [
    'title' => 'Nos chiffres clés',
    'items' => [
        [
            'value' => '25',
            'prefix' => '+',
            'suffix' => 'ans',
            'title' => 'd’expérience',
        ],
        [
            'value' => '98',
            'suffix' => '%',
            'title' => 'de satisfaction',
            'text' => '<p>Mesurée auprès de nos clients.</p>',
        ],
    ],
]);
Contrat
Clé Type Défaut Rôle
title scalar|Stringable '' Titre facultatif
text scalar|Stringable '' Texte facultatif
link array [] Lien interne ou externe facultatif
items list<array> [] Payloads transmis à card-keynumber
options array [] Options communes traitées par options()

Les lignes plates et les lignes imbriquées sous card sont acceptées, ce qui permet de réutiliser le groupe ACF Card - keynumber par clonage. Les items sans value sont ignorés. La strate ne produit aucun balisage lorsqu’aucun chiffre valide n’est fourni.

Le titre et l’introduction Lorem viennent des default_value ACF. Le manifeste préremplit quatre chiffres clés de démonstration afin que la grille soit visible dès l’ajout de la strate dans Forge.

Assets

La strate ne possède aucun JavaScript. Son SCSS organise la liste ; le rendu de chaque item appartient à card-keynumber. Le design du starter reste volontairement neutre : titre de strate en h2, titres des cards en h3, couleur d’accent sur les valeurs et séparateur simple, sans image, icône, fond décoratif ni animation.
