Hero Homepage

Utilisation

Le premier appel charge automatiquement le champ ACF hero-homepage. Le second utilise directement les données fournies.

hero('homepage');
hero('homepage', ['title' => 'Test']);
Data Contract
[
    'suptitle' => 'Surtitre',
    'title' => 'Titre de la page',
    'text' => '<p>Introduction éditoriale.</p>',
    'images' => [
        'desktop' => 123,
        'mobile' => 124,
    ],
]

Le manifeste fournit un surtitre, un titre et un texte Lorem ipsum, ainsi que deux images de démonstration depuis assets/img/placeholders/. Forge les affiche comme valeurs initiales puis les importe dans la médiathèque lors de la création du site. Les identifiants ACF enregistrés sont donc propres à chaque installation WordPress. Ces valeurs servent au préremplissage dans Forge, pas de fallback PHP : un champ volontairement vidé reste vide. Pour un site déjà créé, la synchronisation du catalogue ne remplace pas les contributions existantes.
