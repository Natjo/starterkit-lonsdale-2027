Strate Accordion

Affiche un titre, un texte d’introduction et une liste de contenus repliables.

Appel
strate('accordion', [
    'title' => 'Questions fréquentes',
    'text' => '<p>Introduction.</p>',
    'items' => [
        [
            'title' => 'Question',
            'text' => '<p>Réponse.</p>',
        ],
    ],
]);
Contrat
Clé Type Rôle
title string Titre de la strate
text string Introduction éditoriale
items array Éléments transmis à component('accordion')
items[].title string Libellé de l’élément
items[].text string Contenu déplié

Le manifeste fournit un contenu Lorem et trois éléments de démonstration. Forge les utilise uniquement pour préremplir une nouvelle instance.

Dépendances
  • component('title', [...]) ;
  • component('text', [...]) ;
  • component('accordion', [...]).

La strate ne produit aucun HTML sans contenu exploitable. Les champs absents sont traités comme vides.

Background

Strate columns-content

Affiche de une à trois colonnes éditoriales. Chaque colonne peut contenir un titre, un texte riche et une image.

Appel
strate('columns-content', [
    'columns' => [
        [
            'title' => 'Première colonne',
            'text' => '<p>Contenu éditorial.</p>',
            'image' => 123,
        ],
    ],
]);
Contrat
Clé Type Rôle
columns array De 1 à 3 colonnes ; les entrées supplémentaires sont ignorées
columns[].title mixed Transmis à component('title')
columns[].text mixed Transmis à component('text')
columns[].image ID|URL|null Transmis à component('picture')
options array Options communes traitées par options()

Les colonnes entièrement vides ne sont pas rendues. Si aucune colonne ne contient de donnée exploitable, la strate ne produit aucun HTML.

Champs ACF

Le layout columns-content contient un repeater columns, obligatoire, avec un minimum de 1 et un maximum de 3 lignes. Chaque ligne contient title, text et image.

Le manifeste préremplit trois colonnes de démonstration. Leurs images dédiées mesurent 960 × 640 px et sont importées dans la médiathèque par Forge lors de la création du site.

Dépendances
  • component('picture') ;
  • component('title') ;
  • component('text').

Strate keynumbers

Affiche une introduction facultative suivie d’une liste de chiffres clés. Chaque item est rendu par card-keynumber.

Lire d’abord le README général des strates et le README de la card.

Appel
strate('keynumbers', [
    'title' => 'Nos chiffres clés',
    'items' => [
        [
            'value' => '25',
            'prefix' => '+',
            'suffix' => 'ans',
            'title' => 'd’expérience',
        ],
        [
            'value' => '98',
            'suffix' => '%',
            'title' => 'de satisfaction',
            'text' => '<p>Mesurée auprès de nos clients.</p>',
        ],
    ],
]);
Contrat
Clé Type Défaut Rôle
title scalar|Stringable '' Titre facultatif
text scalar|Stringable '' Texte facultatif
link array [] Lien interne ou externe facultatif
items list<array> [] Payloads transmis à card-keynumber
options array [] Options communes traitées par options()

Les lignes plates et les lignes imbriquées sous card sont acceptées, ce qui permet de réutiliser le groupe ACF Card - keynumber par clonage. Les items sans value sont ignorés. La strate ne produit aucun balisage lorsqu’aucun chiffre valide n’est fourni.

Le titre et l’introduction Lorem viennent des default_value ACF. Le manifeste préremplit quatre chiffres clés de démonstration afin que la grille soit visible dès l’ajout de la strate dans Forge.

La strate ne possède aucun JavaScript. Son SCSS organise la liste ; le rendu de chaque item appartient à card-keynumber. Le design du starter reste volontairement neutre : titre de strate en h2, titres des cards en h3, couleur d’accent sur les valeurs et séparateur simple, sans image, icône, fond décoratif ni animation.

Background

Strate logos

Affiche une grille statique de logos de partenaires ou clients, sans animation.

strate('logos', [
    'title' => 'Nos partenaires',
    'logos' => [
        [
            'name' => 'Partenaire',
            'image' => 123,
            'link' => ['url' => 'https://example.com', 'title' => 'Site du partenaire'],
        ],
    ],
]);

Le layout ACF propose un titre et un texte d'introduction facultatifs, puis un repeater logos. Chaque ligne demande une image ID et accepte un name et un link ACF facultatifs. Le nom sert de texte alternatif explicite ; sinon, le titre du lien puis le texte alternatif du média sont utilisés. Le lien entoure l'image uniquement lorsqu'il possède une URL valide. Une ligne sans image est ignorée ; sans logo valide, la strate ne rend rien. options applique les options communes.

La strate utilise les composants header et picture. Le manifeste préremplit l'introduction, mais laisse logos vide : aucun faux partenaire ni visuel sans rapport n'est ajouté au site.

strate-marquee

Conteneur

Marges

Background

Strate marquee

Affiche un défilement continu de cards ou d’images. Le starter utilise par défaut le mode images avec trois visuels de démonstration.

Lire d’abord le README général des strates et le README du composant marquee.

Appel

Cards :

strate('marquee', [
    'title' => 'À découvrir',
    'content_type' => 'cards',
    'post_type' => 'news',
    'items' => [123, 456],
]);

Images :

strate('marquee', [
    'content_type' => 'images',
    'images' => [
        ['image' => 123],
        ['image' => 456],
    ],
]);

Le mode HTML reste disponible lors d’un appel PHP :

strate('marquee', [
    'content_type' => 'html',
    'items' => ['<strong>Design</strong>', '<span>Digital</span>'],
]);
Contrat
Clé Type Défaut Rôle
title scalar|Stringable '' Titre facultatif
text scalar|Stringable '' Texte facultatif
link array [] Lien interne ou externe facultatif
content_type 'html'|'cards'|'images' 'images' Nature des items
post_type string '' CPT en mode cards
card string Valeur de post_type Card utilisée lors d’un appel PHP
items list<int|array|scalar|Stringable> [] Cards ou HTML direct
images list<array{image?: ID}> [] Images ACF
marquee_options array [] Réglages transmis au marquee
options array [] Options communes traitées par options()

Une strate sans card valide, image exploitable ou contenu HTML ne produit aucun balisage.

Champs ACF

Pause au survol marquee_options.pause_on_hover Vrai/faux —
Pause au focus marquee_options.pause_on_focus Vrai/faux —
Options options Groupe cloné —

ACF propose automatiquement les CPT enregistrés qui possèdent une card de même nom. Dans le starter, le choix par défaut est news.

Les posts sélectionnés sont préchargés en lots avant leur validation par CPT. Les images sont ensuite préchargées par le composant marquee. Ce comportement s'applique à toutes les pages, archives et templates utilisant la strate.

Images

La taille WordPress est définie au début du template :

$image_size = 'full';

Les images utilisent picture avec fit => 'cover'. Le starter leur applique un ratio 3 / 2 et une largeur maximale de 48rem. Les trois placeholders de 960 × 640 px sont déclarés dans le manifeste puis importés par Forge. Ils sont partagés avec Columns Content afin d’éviter les doublons dans la médiathèque.

Hydratation

La strate possède le cycle de vie JavaScript. Elle force hydrate => false sur le composant et délègue pause, resume et destroy à son contrôleur.

Strate media

Affiche une image ou une vidéo sur le rail défini par les options communes de strate. Elle convient aux projets qui préfèrent une seule strate avec un choix image/vidéo ; image et video restent disponibles comme variantes séparées.

Lire d’abord le README général des strates.

Appel
strate('media', [
    'media_type' => 'image',
    'image' => 123,
]);

strate('media', [
    'media_type' => 'video',
    'video' => 'https://vimeo.com/123456789',
    'video_title' => 'Présentation du projet',
]);

La strate ne produit aucun balisage lorsque la source correspondant au type sélectionné est vide.

Contrat
Clé Type Défaut Rôle
media_type 'image'|'video' 'image' Sélectionne le composant rendu
image ID|URL|null Placeholder du manifeste Transmise à component('picture')
video ID|URL|null null Transmise à component('video')
video_title scalar|Stringable '' Nom accessible du lecteur vidéo
options array [] Options communes traitées par options()

Les anciennes clés is_image et video-title restent interprétées par le template pour assurer la compatibilité des payloads existants.

Champs ACF
acf_fc_layout = media
Libellé Identifiant Type ACF Format
Type de média media_type Groupe de boutons image ou video
Image image Image conditionnelle requise ID de média
Vidéo video URL conditionnelle requise URL complète
Titre de la vidéo video_title Texte conditionnel Texte simple
Options options Groupe cloné Options communes des strates

Le champ URL convient aux vidéos externes ou aux fichiers accessibles par une URL. Pour sélectionner une vidéo dans la médiathèque sur un site client, remplacer ce champ par un champ Fichier retournant un ID.

Le mode par défaut est image. Son placeholder dédié mesure 1672 × 941 px, soit un ratio proche de 16:9 adapté à l’affichage pleine largeur. Forge l’importe dans la médiathèque lors de la création du site.

Assets et dépendances

La strate n’a pas d’asset propre. Elle utilise :

  • options() ;
  • component('picture', [...]) ;
  • component('video', [...]).

strate-pushes

Conteneur

Marges

Background

Strate pushes

Affiche, dans l’ordre choisi, des contenus existants sous forme de cards. Lire d’abord le README général des strates.

strate('pushes', [
    'title' => 'À la une',
    'items' => [123, 456],
]);
Contrat
Clé Type Défaut Rôle
title scalar|Stringable '' Titre facultatif
text scalar|Stringable '' Texte facultatif
link array [] Lien ACF interne ou externe
items list<int> [] IDs des contenus sélectionnés, dans l’ordre voulu
options array [] Options communes traitées par options()

Dans le BO, le layout flexible pushes propose uniquement les champs de présentation, la liste « Contenus » (relation ACF) et les options communes. La liste est limitée aux types ayant une card de même nom dans le starter. Chaque contenu utilise la card associée à son type via theme_content_type_card. Les IDs sont dédupliqués, les contenus sans card ignorés. Il n’y a ni choix de mode, ni création de push manuel dans la strate.

Le payload provient de theme_post_card_item : groupe ACF card facultatif, champs métier configurés, puis données WordPress. Sans introduction ni contenu valide, la strate ne produit aucun balisage.

Dépendances

La strate utilise component('header') et les cards associées aux types sélectionnés. Son SCSS est co-localisé avec ce README. Le manifeste préremplit l'introduction, mais laisse items vide : les IDs des publications doivent provenir du site créé.

Strate pushes-more

Remonte automatiquement les derniers contenus publiés d’un type et ajoute un bouton « Voir plus ». Le bouton charge le lot suivant en AJAX ; son URL reste utilisable sans JavaScript. Lire le README général.

strate('pushes-more', [
    'title' => 'Actualités',
    'post_type' => 'news',
    'limit' => 3,
    'more_label' => 'Voir plus',
]);
Contrat
Clé Type Défaut Rôle
title scalar|Stringable '' Titre facultatif
text scalar|Stringable '' Texte facultatif
link array [] Lien facultatif
post_type string '' Type enregistré avec card
card string Card du type Remplacement facultatif en PHP
limit int 3 Taille du lot, de 1 à 12
more_label string Voir plus Libellé du bouton
options array [] Options communes

Le layout ACF pushes-more expose ces champs, sans sélection manuelle. Chaque instance utilise un paramètre d’URL propre (pushes_more_N) afin que plusieurs strates puissent cohabiter sur la même page. Une visite directe de l’URL affiche le lot demandé ; le module JS récupère cette page et ajoute ses cards au lot déjà visible. Le lien disparaît après le dernier lot.

La requête et la préparation des cards sont partagées avec pushes-auto via theme_pushes_items(). Les variantes ACF card et les champs métier sont appliqués par theme_post_card_item().

Dépendances

La strate utilise component('header'), component('list'), la card du type choisi et son module JS co-localisé. Le module est hydraté à l’approche du viewport et annule ses requêtes à la destruction.

strate-slider-cards

Conteneur

Background

Strate slider-cards

Affiche des cards éditoriales rédigées directement dans le BO, sans relation avec une page, un post ou un CPT. Lire le README général, le README du slider et celui de card-slide.

strate('slider-cards', [
    'title' => 'À découvrir',
    'items' => [
        ['title' => 'Premier sujet', 'text' => '<p>Présentation.</p>', 'image' => 123],
        ['title' => 'Second sujet', 'link' => ['url' => '/sujet/', 'title' => 'Lire']],
    ],
]);

Le layout ACF slider-cards propose un répéteur items limité à 12 lignes. Chaque ligne contient title, text, image (ID) et link, correspondant au manifeste de card-slide. Titre, texte, lien de la strate, réglages du slider, libellé accessible et options communes restent distincts des champs de chaque card.

Une ligne sans titre, texte ni image est ignorée. Sans card valide, aucun balisage n’est produit. Le composant slider gère sa propre hydratation JS ; la strate n’a pas de module dédié.

Les lignes peuvent aussi être imbriquées sous card, pour réutiliser le groupe ACF Card - slide par clonage, sans préfixage de ses noms de champs.

Version 1.0.0

strate-slider-images

Conteneur

Marges

Background

Strate slider-images

Affiche un carrousel d’images saisies dans le BO. Cette variante ne contient ni cards ni requête de publications. Lire le README général et le README du slider.

strate('slider-images', [
    'title' => 'Galerie',
    'images' => [['image' => 123], ['image' => 456]],
    'slider_options' => ['navigation' => true, 'pagination' => true],
]);

Le layout ACF slider-images propose titre, texte, lien, répéteur images avec un champ image retournant un ID, réglages slider_options (navigation, pagination, timeline), aria_label et options communes. Les lignes sans image sont ignorées. Sans image valide, aucun balisage n’est produit.

Les images sont transmises au composant slider via picture, en taille full et fit: cover. Le composant hydrate lui-même son JavaScript à l’approche du viewport. Les trois images du manifeste sont des placeholders destinés à Forge.

strate-snap

Conteneur

Marges

Background

Strate snap

Strate composée de sections éditoriales configurées dans le repeater ACF slides. Elle les parcourt comme un slider vertical sur ordinateur, sans Swiper ni lenis-snap. La navigation et le comportement sont délégués au composant section-snap.

Appel
strate('snap', [
    'slides' => [
        [
            'title' => 'Expertises',
            'text' => '<p>Notre savoir-faire.</p>',
            'image' => 123,
            'link' => ['url' => '/expertises/', 'title' => 'Découvrir'],
            'background_color' => 'color-2',
        ],
    ],
]);

Chaque ligne contient un titre obligatoire, un texte WYSIWYG, une image ID, un lien ACF et une couleur de fond facultatifs. Les couleurs autorisées sont color-1, color-2 et color-3 ; none laisse le fond par défaut. Une ligne sans titre est ignorée. Si aucune ligne valide ne reste, la strate ne produit aucun HTML. Le titre sert aussi de libellé dans la navigation.

Le manifeste fournit trois sections de démonstration préremplies dans Forge. L'onglet Options ACF reprend les options communes des strates.

Le composant configure la ligne d’activation :

sectionSnap(root, {
    slideSelector: ":scope > .strate",
    navSelector: ":scope > .snap-nav",
    activationOffset: "var(--header-height)",
    deactivationOffset: "var(--header-height)",
    breakpoint: 1025,
});

activationOffset et deactivationOffset peuvent être remplacés indépendamment par une autre longueur CSS, un pourcentage, un calc() ou un nombre de pixels. Les pourcentages sont relatifs à la hauteur du viewport : "50%" correspond à 50vh. Le premier contrôle l'entrée par le haut du conteneur ; le second contrôle sa sortie par le bas.

breakpoint est une largeur minimale exprimée en pixels. En dessous de 1025px dans cette strate, le snap et ses variables de progression sont désactivés. Si l'option est omise, sectionSnap reste actif quelle que soit la largeur.

Les panneaux sont produits à partir du repeater. Leur navigation est produite avec component('section-snap', ...). Leurs IDs restent uniques si la démonstration est rendue plusieurs fois sur une même page. Chaque panneau mesure au minimum calc(100vh - var(--header-height)), sans marge entre les panneaux, et son ancre l’aligne immédiatement sous le header fixe. Un contenu long agrandit le panneau ; les images portrait sont contenues dans la hauteur disponible.

Navigation verticale

Sur un appareil où le Lenis global est disponible :

  • le snap reste inactif tant que le haut de .strate-snap n'a pas atteint la ligne définie par var(--header-height) ;
  • au franchissement descendant de cette ligne, le scroll s'arrête immédiatement sur la première slide, alignée sous le header, sans transition corrective de quelques pixels ;
  • une impulsion verticale de molette sélectionne la strate suivante ou précédente ;
  • les faibles deltas d'un trackpad sont cumulés jusqu'au seuil de 40px ;
  • la transition dure 0.9s avec une décélération en fin de course ;
  • lock: true empêche plusieurs changements de slide pendant la transition ;
  • ArrowUp, ArrowDown, PageUp et PageDown utilisent les mêmes cibles ;
  • un déplacement effectué avec la scrollbar rejoint la strate la plus proche lorsque la scrollbar est relâchée ;
  • le scroll redevient normal avant la première strate et après la dernière ;
  • un conteneur interne scrollable conserve la priorité tant qu'il peut encore défiler dans la direction demandée ;
  • une strate plus haute que le viewport défile naturellement avant que la cible suivante soit aimantée.

Le relâchement de la scrollbar utilise l'événement scrollend, avec un debounce de repli pour les navigateurs qui ne le prennent pas en charge. Les positions sont recalculées avec ResizeObserver. Lenis tient compte du scroll-margin-top défini sur chaque strate.

Progression visuelle --i

Chaque .strate reçoit une variable CSS --i actualisée pendant le scroll :

  • 1 lorsque la strate est exactement placée sur sa cible ;
  • une valeur intermédiaire pendant son arrivée ou sa sortie ;
  • 0 lorsqu'elle atteint la position de la strate voisine.

La première slide constitue une exception : elle reste à 1 pendant l'arrivée dans la strate snap, puis diminue de 1 à 0 en direction de la deuxième slide. Elle est ainsi déjà complètement visible lorsque le conteneur entre dans le viewport.

La dernière slide suit le comportement miroir : elle augmente de 0 à 1 pendant son arrivée, puis reste à 1 lorsque le viewport quitte la strate snap.

La progression fonctionne dans les deux directions et peut piloter directement un fondu :

.strate-snap > .strate {
    opacity: var(--i, 1);
}

La variable inline est retirée lors de la destruction du module.

Parallaxe --p

Chaque slide reçoit aussi une progression signée indépendante de l'opacité :

  • 1 avant que la slide atteigne sa cible ;
  • 0 lorsqu'elle est placée ;
  • -1 après son passage.

La .paralax l'utilise sur ordinateur pour arriver depuis le bas et sortir vers le haut :

.paralax {
    translate: 0 calc(var(--p, 0) * 8rem);
}

Le déplacement est désactivé avec prefers-reduced-motion: reduce. La variable inline est retirée avec --i lors de la destruction du module.

Le changement de slide émet aussi l'événement snap:change sur la racine :

root.addEventListener("snap:change", ({ detail }) => {
    console.log(detail.index, detail.slide);
});
Navigation d'ancres

Le composant section-snap contrôle directement le menu .snap-nav qu’il produit. Le menu suit la strate active pendant les transitions, ses liens utilisent le même Lenis global et son curseur est recalculé avec le layout. Le lien cible devient actif dès le lancement du snap, sans attendre la fin de la transition, et reste verrouillé jusqu'à son terme. Il ne faut pas initialiser un autre module de navigation sur ce menu.

Replis et accessibilité

Le contrôleur ne capture aucun geste lorsque Lenis est absent. C'est notamment le cas sur les pointeurs tactiles avec la configuration actuelle du projet. Le document conserve alors son scroll vertical natif.

Avec prefers-reduced-motion: reduce, aucun geste n'est intercepté. Les champs de formulaire, les zones contenteditable, les éléments portant data-snap-ignore, data-lenis-prevent ou data-lenis-prevent-wheel gardent également leur comportement normal.

Le composant retourne le lifecycle complet à l’hydrateur, qui peut suspendre ou détruire ensemble le snap et sa navigation.

Dépendances
  • le Lenis global exposé dans window.lenis ;
  • assets/components/section-snap/section-snap.js ;
  • assets/components/section-snap/section-snap.scss ;
  • assets/strates/strate-snap/strate-snap.scss.

strate-steps

Conteneur

Marges

Background

Strate steps

Affiche une suite ordonnée d'étapes. La numérotation est générée par CSS et reste correcte lorsque des lignes incomplètes sont ignorées.

strate('steps', [
    'title' => 'Notre méthode',
    'steps' => [
        ['title' => 'Écouter', 'text' => '<p>Votre besoin.</p>'],
        ['title' => 'Créer', 'link' => ['url' => '/contact/', 'title' => 'Nous contacter']],
    ],
]);

Le layout ACF propose un titre et un texte d'introduction facultatifs, puis un repeater steps. Chaque ligne demande un title et accepte un text WYSIWYG et un link ACF facultatifs. Une ligne sans titre est ignorée ; sans étape valide, la strate ne rend rien. options applique les options communes.

Le manifeste fournit trois étapes d'exemple pour Forge. La strate utilise les composants header, title, text et link.

strate-text

Conteneur

Marges

Background

Strate Text

Affiche un titre et un contenu éditorial riche.

Appel
strate('text', [
    'title' => 'Lorem ipsum dolor sit amet',
    'text' => '<p>Contenu éditorial.</p>',
]);
Contrat
Clé Type Rôle
title string Titre de la strate
text string HTML éditorial transmis à component('text')

Le contenu de démonstration défini dans ACF présente les formats disponibles :

  • titres h2, h3 et h4 ;
  • format Intro (.intro) et Petit texte (small) ;
  • gras, italique, souligné et lien ;
  • citation ;
  • listes à puces et numérotées.

Forge reprend ces default_value uniquement lors de l’initialisation d’une nouvelle strate.

Dépendances
  • component('title', [...]) ;
  • component('text', [...]).

La strate ne produit aucun HTML sans contenu exploitable. Les champs absents sont traités comme vides.

strate-text-animated

Conteneur

Marges

Background

Strate text-animated

Strate statique de démonstration du catalogue. Elle présente un titre dont les caractères se révèlent progressivement en fonction du scroll grâce au module textAnimated.

strate('text-animated');
Contrat
  • la strate ignore tous les arguments transmis ;
  • son contenu est volontairement écrit directement dans le template ;
  • elle n'est pas déclarée dans le flexible content ACF ;
  • le premier descendant .text-animated est la cible de l'animation ;
  • la révélation reprend la couleur de texte héritée : elle fonctionne donc sur un fond clair comme sur un fond sombre ;
  • avec prefers-reduced-motion: reduce, le titre reste lisible et n'est pas découpé en caractères.
Hydratation

La strate possède son cycle de vie avec data-module="strates/strate-text-animated". Son module JavaScript importe textAnimated, lui transmet la racine de la strate et retourne directement son lifecycle { pause, resume, destroy } à l'hydrateur.

Hors écran, la strate est retirée du singleton ScrollDriver. Lorsqu'elle revient, elle est réinscrite sans doublon. destroy() restaure définitivement le DOM original.

Le module partagé gère le découpage avec splitText, la progression avec ScrollDriver et la restauration du DOM au nettoyage. Ne pas ajouter une seconde hydratation sur le titre.

Le manifeste déclare explicitement les modules scrollDriver et splitText : les deux doivent être conservés par Forge lorsqu’un site utilise cette strate. Son defaults est vide, car le template de démonstration ignore tout payload.

strate-text-image

Conteneur

Background

Strate text-image

Affiche un bloc éditorial composé d’un titre, d’un texte riche et d’une image. À partir du breakpoint md, le contenu et le média occupent chacun une moitié du rail ctr.

Lire d’abord le README général des strates.

Appel

Depuis le flexible content ACF, le dispatcher appelle automatiquement :

strate('text-image', $strate);

Appel direct :

strate('text-image', [
    'title' => 'Titre de la section',
    'text' => '<p>Contenu éditorial.</p>',
    'image' => 123,
    'reverse' => true,
    'center' => true,
]);

Le nom du layout ACF est text-image. Le préfixe strate- appartient uniquement au dossier et au fichier PHP.

Options
Option Effet à partir du breakpoint md
reverse Place l’image à gauche et le texte à droite
center Centre verticalement le texte et l’image
Contrat
Clé Type Valeur ACF vide Rôle
title mixed Titre Lorem ipsum Transmis à component('title')
text mixed Deux paragraphes Lorem ipsum Transmis à component('text')
image ID|URL|null Placeholder du manifeste Transmis à component('picture')
reverse bool false Inverse les colonnes à partir du breakpoint md
center bool false Centre verticalement les deux colonnes
options array [] Options communes traitées par options()
Champs ACF

Layout flexible content :

acf_fc_layout = text-image
Libellé Identifiant Type ACF Format
Titre title WYSIWYG léger HTML éditorial filtré par le composant
Texte text WYSIWYG HTML éditorial filtré par le composant
Image image Image ID de média
Inverser l’ordre reverse Vrai/Faux Booléen, défaut false
Centrer verticalement center Vrai/Faux Booléen, défaut false
Options options Groupe cloné Options communes des strates

Le titre et le texte de démonstration viennent des default_value ACF. Le placeholder dédié mesure 1460 × 973 px, soit deux fois la largeur du format WordPress 730_auto. Il est déclaré dans le manifeste : Forge l’importe dans la médiathèque et remplace sa référence par l’identifiant propre au site créé.

Mise en page

Avant le breakpoint md, le texte et l’image sont empilés.

À partir du breakpoint md, ils occupent chacun une moitié du rail ctr :

  • reverse inverse leur position ;
  • center les centre verticalement.

Dépendances :

  • options() ;
  • component('title', [...]) ;
  • component('text', [...]) ;
  • component('picture', [...]).

La strate ne produit aucun HTML sans contenu exploitable. Les champs absents sont traités comme vides.

strate-video

Conteneur

Marges

Background

Strate video

Affiche une vidéo HTML5, YouTube ou Vimeo via component('video'). Lire d’abord le README général et celui du composant video.

strate('video', [
    'video' => 'https://vimeo.com/123456789',
    'video_title' => 'Présentation du projet',
    'poster' => 123,
]);

Le layout ACF video contient video (URL complète), video_title (nom accessible), poster (image facultative retournant un ID) et les options communes. La strate ne produit aucun balisage sans source.

Le poster active la façade locale du composant et attend un clic. Sans poster, les lecteurs externes ne chargent qu’à l’entrée dans le viewport. Le JavaScript appartient au composant video, pas à la strate. Le manifeste laisse video vide : le starter n'embarque pas de fichier vidéo de démonstration et n'impose pas de source externe.
